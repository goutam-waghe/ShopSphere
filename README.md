ShopSphere is a single-vendor e-commerce platform. Customers can discover products, search and filter the catalogue, manage a cart and wishlist, provide a delivery address, place an order, and pay online. Administrators manage the catalogue, categories, stock, customers, and order statuses.


## Frontend

The ShopSphere frontend is built using **Next.js, React, TypeScript, and Tailwind CSS**. It provides a responsive interface for customers and administrators.

### Technology Stack
- Next.js – Frontend framework
- TypeScript – Type safety
- Tailwind CSS – Styling
- Shadcn UI – UI components
- Axios – API integration
- TanStack Query – Server state management
- Zustand – Client state management
- React Hook Form + Zod – Form handling and validation

### Customer Features
- Login and Registration
- Homepage and Product Listing
- Product Details and Search
- Product Filters and Sorting
- Shopping Cart and Wishlist
- Checkout and Razorpay Payment
- Order History and Details
- Profile and Address Management

### Admin Features
- Admin Dashboard
- Product Management
- Category Management
- Inventory Management
- Order Management
- Customer Management

### Frontend Requirements
- Responsive design (mobile, tablet, desktop).
- Backend API integration.
- Protected customer and admin routes.
- Form validation and error handling.
- Reusable UI components.
- Loading, success, and empty states.
